# S’NAIL BOOK v0.2.0

Extra v115 원본 42개 파일을 확인한 후, 기존 4개 하단 메뉴 SVG 및 유지 대상 설정 아이콘, 화면 스타일 규칙을 반영한 네일샵용 독립 PWA입니다. 원본 Extra와 별도 저장 키를 사용합니다.

기능: 월·주·일 달력, 고객별 예약·시술·연락처, 서비스 가격 및 소요시간, 추가비용·할인, 예약 중복 경고, 시술/결제 상태, 결제 완료 내역만 고객별 매출 집계, 백업·복원, 초기화.

배포: 이 폴더의 **내용물 전체**를 별도의 GitHub Pages 저장소 루트에 업로드 → Settings / Pages / Deploy from branch / main / root 선택 → Safari에서 HTTPS로 연 다음 홈 화면에 추가.

Google 캘린더 연결은 실제 사용자에게 앱을 전달한 후 연동하는 것으로 합의하여 현재 보류했습니다.

현재 데이터는 기기 내 localStorage 저장이므로 주기적으로 JSON 백업을 권장합니다. 원본 Extra의 iframe 달력 코드를 그대로 쓰지 않고 새로운 예약 달력을 구현했습니다. 아이폰 실기기 검증은 아직 미완료입니다. 자세한 사항은 `SOURCE_AUDIT.md` 참조.
